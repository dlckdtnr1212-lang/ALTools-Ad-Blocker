# ALTools Ad Blocker v2.0 Beta

**알집·알약 광고 팝업 자동 차단 및 제거 유틸리티**

ALTools Ad Blocker는 알집·알약 등 알툴즈 프로그램에서 별도로 실행되는 광고 팝업을 자동으로 감지하고 종료하는 Windows용 유틸리티입니다.

광고 팝업을 매번 직접 닫아야 하는 불편함을 줄이기 위해 개발했습니다.

- 검증 환경: Windows 10 x64
- Windows 11: 미검증
- 다운로드 크기: 약 12.1MB
- 이용 요금: 무료

## 주요 기능

- 알집·알약 관련 광고 팝업 감지 및 자동 종료
- 2초 간격 백그라운드 감시
- Windows 시작 시 자동 실행 지원
- 중복 실행 방지
- 낮은 시스템 자원 사용
- 별도의 Python 설치 불필요

## 사용 방법

1. ZIP 파일을 다운로드합니다.
2. 원하는 폴더에 압축을 해제합니다.
3. `ALTools_Ad_Blocker.exe`를 실행합니다.
4. 프로그램이 백그라운드에서 광고 팝업을 감시합니다.

종료 및 자동 시작 해제, 제거 방법은 ZIP에 포함된 `UNINSTALL.md`를 참고하세요.

## 테스트 및 보안 검사

- Windows 10 x64 실사용 테스트
- 광고 프로세스 감지 및 종료 기록 확인
- 알약 검사 결과: 탐지된 항목 없음
- 배포 ZIP 무결성 검사 통과
- 배포 EXE 해시 일치 확인

## 참고사항

- 알툴즈 프로그램 내부 배너 광고는 제거하지 않습니다.
- 광고가 순간적으로 나타났다가 종료될 수 있습니다.
- 알툴즈 업데이트에 따라 차단 동작이 달라질 수 있습니다.
- Windows 11에서는 아직 검증하지 않았습니다.
